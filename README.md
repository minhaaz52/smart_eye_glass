# Smart Eye Glass

Smart Eye Glass is an assistive project designed to improve mobility and awareness for differently abled users.
It combines obstacle detection and face recognition to help users move more safely and interact with their surroundings with greater confidence.

## Project Objective

The primary goal is to support easier and safer navigation by:

- Detecting nearby obstacles and estimating distance
- Reducing accidental collisions while walking
- Recognizing faces through a camera mounted on the glasses

## Key Features

- Real-time distance estimation
- Obstacle awareness for safer movement
- Face recognition support
- Modular Python scripts for individual functionalities

## Project Structure

- `Final Project/Distance_calculation.py`: Distance and obstacle-related logic
- `Final Project/Face_recognition.py`: Face recognition module
- `Final Project/Final_Program.py`: Integrated final workflow
- `Final Project/index.html`: Supporting web interface/resources
